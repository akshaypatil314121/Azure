C: Drive Disk Space Cleanup – Windows Servers SOP

1.0 Objectives

This document provides step-by-step instructions for listing and performing methods to clear disk space on the C:\ drive for Windows servers.

2.0 Technical Steps

Steps for Mitigating OS (C:) Drive Space Issues

  • Step 1: Log in to the server on which the Low Space alert was triggered.
  • Step 2: Navigate to the C:\ drive and perform Disk Cleanup (basic and system files).

Pre‑Requisites

If Disk Cleanup is not enabled by default (Windows Server 2008 and 2012), the Windows feature "Desktop Experience" must be installed.

Note: Installing Desktop Experience requires a server reboot. Downtime approval must be obtained from the customer, and reboot must be performed under an approved change as per process.

2.1 Install the "Desktop Experience"

  1. Open Server Manager from the Start menu.
  2. Right‑click on Features and select Add Features.
  3. Select Desktop Experience. When prompted, click Add Required Features.
  4. Click Next once the feature is selected.
  5. Click Install and wait for completion. Reboot the server when prompted.

2.2 Steps for Disk Cleanup

  1. Right‑click on the C:\ drive, select Properties, then click Disk Cleanup.

    Note: Disk Cleanup is not available by default on Windows Server 2008 and 2012 unless Desktop Experience is installed. It is available by default on later versions.
  2. Wait for the Disk Cleanup tool to scan available cleanup categories.
  3. Select required categories and click OK to clean them.
  4. For Windows Server 2016 and later, click Clean up system files.
  5. Allow the tool to scan for additional system-related categories.
  6. Select the required system categories and click OK to start cleanup.

Important: Do not delete pagefile.sys. This is a critical system file and deleting it may crash the server.

2.3 Clear CCM Cache

  1. Navigate to the path below and sort folders by Date Modified (ascending order):
C:\Windows\ccmcache
  • Keep folders from the last 30 days.
  • Delete older folders.

If sufficient space is recovered, further steps are not required. Otherwise, continue with the next steps.

2.3 WinSxS Cleanup

  • The WinSxS folder stores Windows update files and component metadata.
C:\Windows\WinSxS

Run the following command from an elevated Command Prompt:

dism.exe /online /Cleanup-Image /StartComponentCleanup

2.4 Clear Unnecessary Data from Users

  1. Identify user profiles older than 30 days.
  2. Navigate to the following path:
C:\Users
  1. Open the specific user folder.
  2. Review the following folders and delete files older than 30 days:
    • Desktop
    • Documents
    • Downloads
