SOP: Resize Azure Virtual Machine and Connect via RDP

4.0 Resize the Virtual Machine

4.1 Navigate to VM Size Settings

  1. Log in to the Azure Portal.
  2. Navigate to Virtual Machines.
  3. Select the target Virtual Machine.
  4. From the left-hand menu, go to:
Availability + Scale → Size

4.2 Select New VM Size

  1. Select Standard B2s:
  • 2 vCPUs
  • 4 GB RAM
  1. Click Resize.
  2. Confirm the resize operation.
✅ The resize process is simple and completes within a short time.
Note: The updated VM size may take a few minutes to reflect. Use the Refresh option if the change is not immediately visible.

5.0 Post‑Resize Validation

  1. Navigate back to the Overview tab of the Virtual Machine.
  2. Verify the VM size shows as Standard B2s.
  3. Confirm the VM status is Running.

6.0 Connect to VM Using RDP

6.1 Download RDP File

  1. On the VM Overview page, click Connect.
  2. Select RDP.
  3. Download the RDP file.
  4. Open the RDP file from the Downloads folder.

6.2 Establish RDP Connection

  1. Click Connect.
  2. Enter the username and password configured during VM creation.
  3. Accept the security prompt.
  4. Wait for the remote session to initialize.
✅ After resizing, the RDP connection should complete successfully and open a Windows Server session.
