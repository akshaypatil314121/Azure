SOP: Add and Attach an Additional Data Disk to an Existing Azure Windows VM

1.0 Objective

This SOP explains how to:

  • Create an Azure managed data disk
  • Attach the disk to an existing Windows Virtual Machine
  • Initialize and format the disk at the OS level
  • Make the disk available for application data storage

2.0 Scope

This procedure applies to Azure Windows Virtual Machines where additional storage is required for application or workload data.

3.0 Prerequisites

  • An existing Azure Windows Virtual Machine
  • Contributor or higher access to the Azure subscription
  • RDP access to the Windows VM
  • VM must be in Running state

4.0 Create and Attach Data Disk (Azure Portal)

4.1 Navigate to Disks

  1. Log in to the Azure Portal.
  2. Go to Virtual Machines.
  3. Select the target Windows VM.
  4. Under Settings, click Disks.

4.2 Create and Attach New Data Disk

  1. Under Data disks, click Create and attach a new disk.
  2. Configure the disk:
  • LUN: 0
  • Disk name: vm01-datadisk
  • Disk type: Premium SSD
  • Disk size: 8 GB
  1. Click Apply.
✅ Azure creates the managed disk and attaches it to the Virtual Machine.

5.0 Initialize Disk on Windows OS

5.1 Open Disk Management

  1. RDP into the Windows VM.
  2. Open Server Manager.
  3. Navigate to File and Storage Services → Disks.

5.2 Initialize the Disk

  1. The new disk appears as Unknown / Not Initialized.
  2. Right‑click the disk and select Initialize Disk.
  3. Click OK to confirm.

5.3 Create New Volume

  1. Right‑click unallocated space and select New Volume.
  2. Accept default settings.
  3. Assign a drive letter (e.g., E:).
  4. Provide a volume label.
  5. Complete the wizard.

6.0 Verification

  1. Open File Explorer on the server.
  2. Verify the new drive is visible (e.g., E:).
  3. Confirm the disk is accessible and ready for use.
✅ The data disk is successfully attached and available for application data storage.

7.0 Best Practices

  • Store application and workload data on data disks, not OS disk
  • Choose disk type based on IOPS and throughput requirements
  • Data disks can also be created during VM provisioning
