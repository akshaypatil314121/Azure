SOP: Introduction to Azure Managed Disks and Data Disks for Virtual Machines

1.0 Objective

This SOP provides an introduction to Azure Managed Disks and explains:

  • The difference between OS disks and data disks
  • When and why additional data disks are required
  • Available Azure managed disk types
  • The importance of IOPS and Throughput

2.0 Scope

This SOP applies to Azure Virtual Machines (Windows and Linux) where additional storage is required to host application or workload data.

3.0 Azure Managed Disks Overview

3.1 OS Disk

  • Every Azure Virtual Machine is created with an OS disk.
  • The OS disk contains operating system files and configurations.
  • It is not recommended to store application or workload data on the OS disk.

3.2 Data Disks

  • Azure allows creation of additional managed data disks.
  • Data disks are separate Azure resources that can be attached to VMs.
  • They are recommended for storing application data, databases, and logs.
✅ Best Practice: Always store application and workload data on separate data disks instead of the OS disk.

4.0 Types of Azure Managed Disks

Azure provides multiple managed disk types based on performance and cost:

  • Standard HDD – Low cost, suitable for minimal I/O workloads
  • Standard SSD – Balanced performance for lightweight applications
  • Premium SSD – High performance, recommended for production workloads
  • Ultra Disk – Highest performance, ideal for enterprise and database workloads

Each disk type differs in maximum size, IOPS, throughput, and cost.

5.0 Understanding IOPS

IOPS (Input/Output Operations Per Second) represents the number of read and write operations a disk can perform per second.

  • Database workloads generate frequent read/write operations
  • Low IOPS can create performance bottlenecks
  • High‑transaction systems require disks with higher IOPS

6.0 Understanding Throughput

Throughput refers to the amount of data that can be transferred per second (MB/s).

  • Critical for workloads handling large files
  • Examples: video uploads, backups, large media content
  • Higher throughput enables faster data transfer

7.0 Disk Selection Considerations

  • Type of workload
  • IOPS requirements
  • Throughput requirements
  • Cost implications
This SOP provides foundational knowledge required before creating and attaching data disks to Azure Virtual Machines.
