SOP: Linux Package Management using YUM, DNF, RPM, and APT

1.0 Objective

  • Understand Linux package management concepts
  • Install, remove, update, and upgrade software packages
  • Understand update vs upgrade
  • Perform rollback using history
  • Use YUM, DNF, RPM, and APT effectively

2.0 Scope

This SOP applies to:

  • RHEL / CentOS / Rocky / Alma Linux (YUM, DNF, RPM)
  • Debian-based distributions such as Ubuntu and Kali Linux (APT)

3.0 What is Package Management?

Package management is the process of managing software packages on a Linux system, including:

  • Installing packages
  • Uninstalling packages
  • Updating packages
  • Upgrading packages
  • Viewing package information
  • Handling dependencies

4.0 Package Management Tools

4.1 YUM (Yellowdog Updater Modified)

  • Used in older RHEL/CentOS versions
  • Automatically resolves dependencies
  • Installs packages from repositories or RPM files

4.2 DNF (Dandified YUM)

  • Modern replacement for YUM
  • Used in RHEL 8 and later
  • Faster and more reliable dependency handling

4.3 RPM (Red Hat Package Manager)

  • Low-level package management tool
  • Does not resolve dependencies automatically
  • Used mainly for querying and manual installs

4.4 APT (Advanced Packaging Tool)

  • Used in Debian-based distributions
  • Manages dependencies automatically

5.0 Installing Packages

Using YUM

sudo yum install nginx

Auto-confirm Installation

sudo yum install nginx -y

Verify Installed Package

nginx -v

6.0 Removing Packages

sudo yum remove nginx
✅ Dependencies are removed automatically during uninstall.

7.0 Update vs Upgrade

Update

  • Keeps older packages
  • Allows rollback
sudo yum update nginx

Upgrade

  • Removes old package version
  • Installs new version
  • No rollback
sudo yum upgrade nginx
⚠️ Update keeps old versions, Upgrade removes them.

8.0 Check Available Updates

sudo yum check-update

9.0 Package History and Rollback

View History

sudo yum history

Undo (Rollback)

sudo yum history undo <ID>

Redo

sudo yum history redo <ID>

10.0 RPM Commands

Install RPM

rpm -ivh package-name.rpm

Remove RPM

rpm -e package-name

Query Installed Packages

rpm -qa

Check Package Info

rpm -qi nginx

List Package Files

rpm -ql nginx

11.0 DNF Commands

dnf list available

dnf list installed

sudo dnf install httpd -y

sudo dnf remove httpd

12.0 APT Commands (Ubuntu)

sudo apt install nginx

sudo apt remove nginx

sudo apt autoremove

13.0 Key Learning Points

  • YUM/DNF handle dependencies automatically
  • RPM is best for querying and manual installs
  • Rollback is possible using YUM/DNF history
  • Choose the tool based on Linux distribution

14.0 Conclusion

Linux package management is a critical system administration skill that enables administrators to maintain stability, control versions, and manage software efficiently.
